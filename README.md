## Flagship projects

**[ABS Financial Systems](https://github.com/abdullahabduljabbarab/abs-financial-systems)**
A distributed financial platform built around one authoritative double-entry ledger: five services on Google Cloud Run, Pub/Sub event delivery, BigQuery CQRS projections, Terraform, and keyless CI/CD through Workload Identity Federation. 16 system requirements verified by 13/13 live black-box failure scenarios.
- [ledger-api](https://github.com/abdullahabduljabbarab/ledger-api): the Python / FastAPI ledger core
- [abs-ledger-spring](https://github.com/abdullahabduljabbarab/abs-ledger-spring): the same invariants on Java 21 and Spring Boot, enforced in PostgreSQL and covered by 15 Testcontainers tests

**[CLEARANCE](https://github.com/abdullahabduljabbarab/CLEARANCE)**
A C++ / Unreal Engine 5 ATC and air-defence synthetic training simulator built around one authoritative simulation state, with 52 automated tests mapped across 69 requirements.
- [clearance-federation](https://github.com/abdullahabduljabbarab/clearance-federation): DIS, Fast DDS, RTI Connext and HLA-Evolved interoperability
- [autopilot-mbd](https://github.com/abdullahabduljabbarab/autopilot-mbd), [radar-mbd](https://github.com/abdullahabduljabbarab/radar-mbd), [missile-mbd](https://github.com/abdullahabduljabbarab/missile-mbd): Simulink / Embedded Coder Model-Based Design
